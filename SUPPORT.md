# Support

Use GitHub Issues for reproducible bugs, compatibility reports, and focused feature requests. Run `scripts/preflight.sh` first and use the matching issue form.

This is a community project without a guaranteed response time or vendor support agreement. General ASUS firmware support, network design, and unrelated Grafana/VictoriaMetrics administration remain outside the project scope.

Report security vulnerabilities through a private GitHub security advisory as described in [SECURITY.md](SECURITY.md), never through a public issue.
