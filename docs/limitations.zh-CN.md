# 已知限制

[English](limitations.md)

- **无线实时流量不等于纯互联网流量。** 它统计 AP 与客户端之间的帧，可能包含局域网通信、重传和计数器重置。
- **Traffic Analyzer 历史是小时级。** 导入器只读取已经结束的小时，保留长度由路由器固件决定。
- **设备更名不会重写历史。** 新名称会形成新的标签组合，长期统计应以 `mac` 聚合。
- **无线发现仍依赖 Broadcom `wl`。** 基础射频会从 `wl_ifnames` 动态发现，并识别 2.4/5/6 GHz；MediaTek 和 Qualcomm 工具仍不支持。
- **部分无线命令失败会拒绝本轮采集。** 合法的空 `assoclist` 会发布 0 台设备；命令错误、状态标记缺失或设备块截断时保留最后一次有效快照，避免发布不完整数据。
- **WAN 与无线实时指标共享一次 SSH 快照。** 无线命令失败会使本轮 WAN 和系统指标也保留最后一次有效值，可通过 exporter stale 状态识别。
- **WAN 摘要只处理当前活动单元。** 不会完整建模双 WAN 负载均衡或故障切换。
- **逻辑 WAN 不一定报告速率。** PPPoE、VLAN 或特殊驱动接口可能没有可靠的 sysfs `speed`；此时不发布速率和利用率，不向下层物理接口猜测映射。
- **Linux 丢包与 IF-MIB discard 语义可能不同。** 迁移前后的两组累计值不保证严格一致。
- **设备名称管理页没有鉴权和 TLS。** 只能监听回环地址或可信内网。
- **示例 systemd 单元以监控服务器 root 运行采集器。** 这是为了匹配原部署 SSH 密钥归属；条件允许时应配置专用账户和独立密钥。
- **暂时没有配置迁移框架。** 升级前需要检查示例配置和 Release Notes。
- **项目不会自动管理数据删除和保留周期。** VictoriaMetrics 保留期和 Grafana 用户管理由运维人员负责。
